# ติว O-NET วิทยาศาสตร์ ป.6 · ม.3

เว็บแอปติวข้อสอบ O-NET วิทยาศาสตร์ แยกตามมาตรฐานและตัวชี้วัดตาม Test Blueprint ของ สทศ.
หน้าเว็บอยู่บน GitHub Pages ข้อมูลอยู่ใน Google Sheets ผ่าน Google Apps Script

## ไฟล์
- `index.html` หน้าเว็บทั้งหมด (นักเรียน + แอดมิน)
- `apps-script/Code.gs` ระบบหลังบ้าน
- `images/` ภาพประกอบข้อสอบที่แคปจาก PDF ต้นฉบับ ชื่อไฟล์ `ระดับ-ปี-ข้อ.png` เช่น `P6-2568-07.png` (ต้องอัปโหลดขึ้น GitHub Pages พร้อม index.html)
- `data/blueprint.tsv` ผังข้อสอบ (Test Blueprint) ปีการศึกษา 2569 ของ ป.6 และ ม.3
- `data/questions-<ระดับ>-<ปี>.tsv` ข้อสอบพร้อมเฉลย เช่น `questions-P6-2568.tsv`
- `data/REVIEW.md` รายการที่ต้องตรวจทานของข้อมูลชุดนี้ (รวมหัวข้อ "สรุปเนื้อหา")
- `data/SUMMARY.md` สรุปรวมข้อสอบ 2561–2568 (สร้างด้วย `node tools/summary.mjs`)
- `data/summaries/` สรุปเนื้อหารายมาตรฐาน หนึ่งไฟล์ต่อมาตรฐานต่อระดับ เช่น `P6-2.1.txt` (ป.6 ว 2.1) `M3-2.3.txt` (ม.3 ว 2.3) และตารางตรวจความครอบคลุมรายข้อ `coverage-*.tsv` / `COVERAGE-*.md`
- `figs/P6.js` `figs/M3.js` ภาพ SVG ประกอบสรุป (แยกตามระดับ เด็ดขาด) **ต้องอัปโหลดขึ้น GitHub Pages พร้อม index.html**
- `source/` ไฟล์ PDF ต้นฉบับจาก สทศ. (`Blueprint-P6-2569.pdf`, `Blueprint-M3-2569.pdf`, `P6-<ปี>.pdf`, `M3-<ปี>.pdf`)

## ติดตั้ง (ประมาณ 10 นาที)
1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script → วางโค้ดจาก `apps-script/Code.gs`
2. เลือกฟังก์ชัน `setup` แล้วกด Run หนึ่งครั้ง → เปิด "บันทึกการดำเนินการ" จดรหัสผ่านของผู้ใช้ `admin` (แสดงครั้งเดียว)
3. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** → คัดลอก URL ที่ลงท้ายด้วย `/exec`
4. เปิด `index.html` ใส่ URL นั้นในบรรทัด `const API_URL = '';`
5. อัปโหลดขึ้น GitHub แล้วเปิด Settings → Pages → Deploy from branch (main, root)

แก้ `Code.gs` ทุกครั้งต้อง Deploy → Manage deployments → แก้ไข → New version

## ใช้งาน
- **ผู้ดูแลกลาง**: เพิ่มโรงเรียน → สร้างแอดมินโรงเรียน → นำเข้าข้อสอบ
- **แอดมินโรงเรียน**: เพิ่มรายชื่อนักเรียน (ห้อง,เลขที่,ชื่อ) ดูรายงานผล เพิ่มแอดมินในโรงเรียนตัวเอง
- **นักเรียน**: กรอก **รหัสห้องเรียน** 6 ตัว (ครูดูได้ที่แท็บ "นักเรียน" ในหน้าแอดมิน) แล้วเลือกชื่อตัวเอง → ฝึกรายมาตรฐาน/ตัวชี้วัด หรือทำข้อสอบจำลองตามผัง

## นำเข้าข้อมูล (เข้าสู่ระบบด้วยผู้ดูแลกลาง)
1. **ผังข้อสอบ**: แท็บ "ผังข้อสอบ" → เลือกไฟล์ `data/blueprint.tsv` → นำเข้าผังข้อสอบ
   ผังเดิมของระดับที่อยู่ในไฟล์จะถูกแทนที่ทั้งหมด (`setup()` สร้างแค่โครงมาตรฐาน ว 1.1–3.2 และ ว 4.1/4.2 แบบยังไม่มีจำนวนข้อ)
   คอลัมน์: `level | year | strand | standard | indicator | description | items | format | points`
   แถวที่ `indicator` ว่าง = ระดับมาตรฐาน ใส่จำนวนข้อ รูปแบบ และคะแนนตามผัง · แถวตัวชี้วัดเว้น items ว่างได้ (ระบบรวมให้ ไม่นับซ้ำ)
2. **ข้อสอบ**: แท็บ "คลังข้อสอบ" → เลือกไฟล์ `data/questions-*.tsv` (หรือวางจาก Google Sheets/Excel) → นำเข้าข้อสอบ
   ระบบตรวจรูปแบบทุกข้อก่อนบันทึก ถ้ามีข้อผิดจะแจ้งเลขข้อและไม่บันทึกทั้งชุด

### รูปแบบไฟล์ข้อสอบ (11 คอลัมน์ ไม่มีหัวตาราง ห้ามมี tab หรือขึ้นบรรทัดใหม่ในเซลล์)
`level | ปีการศึกษา | ข้อที่ | มาตรฐาน | ตัวชี้วัด | โจทย์ | ลิงก์รูป | ตัวเลือก | เฉลย | คำอธิบาย | type`

| type | ความหมาย | คอลัมน์ตัวเลือก | เฉลย |
|---|---|---|---|
| `mc` | ปรนัย 4 ตัวเลือก | ตัวเลือกคั่นด้วย `\|\|` · **เว้นว่าง** ถ้าตัวเลือกอยู่ในภาพ (หน้าเว็บแสดงปุ่ม 1–4) | เลขตัวเลือก เช่น `3` |
| `complex` | เลือกตอบเชิงซ้อน ใช่/ไม่ใช่ | ข้อความย่อยคั่นด้วย `\|\|` (แสดงทีละบรรทัดพร้อมปุ่ม ใช่/ไม่ใช่) | เรียงตามข้อย่อย เช่น `ใช่,ใช่,ไม่ใช่` |
| `order` | เรียงลำดับ | รายการให้เลือกคั่นด้วย `\|\|` (ลำดับในรายการ = หมายเลข 1, 2, 3…) | หมายเลขตามลำดับ เช่น `5,6,4` (จำนวนช่องที่ให้เลือก = จำนวนตัวในเฉลย) |
| `fill` | เติมคำตอบ | เว้นว่าง | คำตอบที่ต้องพิมพ์ให้ตรง |

- **เฉลยหลายคำตอบ** (กระดาษเฉลยของ สทศ. ระบายสองช่องในข้อเดียวกัน): คั่นด้วย `|` ภายในช่องเดียว ระบบนับถูกทั้งสองคำตอบ ไม่เลือกให้เอง · ปรนัย `1|2` · เชิงซ้อนคั่นเป็นรายข้อย่อยด้วย `,` เช่น `ใช่,ใช่|ไม่ใช่,ไม่ใช่` (ข้อย่อยที่ 2 รับได้ทั้ง ใช่ และ ไม่ใช่) · หน้าเฉลยแสดง "1 หรือ 2" · ปัจจุบันมี M3-2561 ข้อ 26 และ P6-2561 ข้อ 31.2 · ทดสอบตรรกะด้วย `node tools/test/alts.mjs`
- ถ้าไม่ใส่ `type` ระบบถือเป็น `mc` เมื่อมีตัวเลือก และ `fill` เมื่อตัวเลือกว่าง (ไฟล์ 10 คอลัมน์แบบเดิมจึงยังนำเข้าได้)
- **ลิงก์รูป**: ใส่ชื่อไฟล์ (เช่น `P6-2568-07.png`) ระบบจะแสดงจากโฟลเดอร์ `images/` ของเว็บ หรือใส่ลิงก์ `https://…` ก็ได้ ภาพแสดงทั้งหน้าทำข้อสอบ หน้าเฉลย และตอนพิมพ์ PDF
- **ขีดเส้นใต้**: ครอบข้อความด้วย `__…__` ในโจทย์ ตัวเลือก หรือคำอธิบาย เช่น `ข้อใด__ไม่__ถูกต้อง`
- **มาตรฐาน/ตัวชี้วัด**: รูปแบบ `ว 2.3` และ `ป.6/1` หรือ `ม.3/2` ตามหลักสูตรฯ ฉบับปรับปรุง 2560
  ข้อที่ตัวชี้วัดไม่อยู่ในผังปีล่าสุดของชีต Blueprint ให้คงตัวชี้วัดจริงไว้ หน้าเว็บจะติดป้าย "ไม่อยู่ในผัง 2569" ให้เอง (หน้าสรุป หน้าสรุปเนื้อหา และหน้าข้อสอบ)

### การให้คะแนน
คะแนนต่อข้อตามผังข้อสอบ ปีการศึกษา 2569 (ตั้งไว้ที่ `POINTS` ใน `Code.gs`)
- ป.6: ปรนัย 5 · เลือกตอบเชิงซ้อน 5 (รวม 100)
- ม.3: ปรนัย 2.75 · เรียงลำดับ 2.75 · เลือกตอบเชิงซ้อน 4 (รวม 100)
- **ข้อเชิงซ้อน** ให้คะแนนบางส่วนตาม "เกณฑ์การให้คะแนน" ในคำชี้แจงของข้อสอบแต่ละฉบับ (ตาราง `PARTIAL` ใน `Code.gs` แยกตาม ระดับ-ปี)
  เก็บเป็นสัดส่วนของคะแนนเต็ม (คะแนนเต็มใช้ตามผัง 2569) ทุกฉบับที่พิมพ์เกณฑ์ไว้ใช้ "ถูก 3 ข้อย่อยได้เต็ม · ถูก 2 ได้ครึ่งหนึ่ง · ถูก 1 หรือ 0 ได้ 0"
  เช่น ป.6 2561 พิมพ์ 5 · 2.5 · 0 | ป.6 2562 พิมพ์ 4.5 · 2.5 · 0 | ป.6 2563 พิมพ์ 6.3 · 3.15 · 0 | ป.6 2564–2568 พิมพ์ 5 · 2.5 · 0 | ม.3 2561 พิมพ์ 4 · 2 · 0 | ม.3 2562 พิมพ์ 5 · 2.5 · 0 | ม.3 2563 พิมพ์ 5.2 · 2.6 · 0 | ม.3 2564–2567 พิมพ์ 4 · 2 · 0
  ฉบับที่ไม่ได้พิมพ์เกณฑ์บางส่วน (เช่น ม.3 2568) ต้องถูกทุกข้อย่อยจึงได้คะแนน · ปีใหม่ที่นำเข้าให้เพิ่มแถวใน `PARTIAL` ตามคำชี้แจงของฉบับนั้น
- **ข้อเรียงลำดับ** ไม่มีฉบับใดพิมพ์เกณฑ์บางส่วน ต้องถูกทุกลำดับจึงได้คะแนน
- ข้อความย่อยของข้อเชิงซ้อนที่เป็นชื่อไฟล์ภาพล้วน (เช่น `M3-2567-34-1.png`) แสดงเป็นภาพที่แคปจากต้นฉบับ ใช้เมื่อข้อย่อยเป็นรูป/วงจร
- ชนิดที่ผังของระดับนั้นไม่มี (ป.6 เรียงลำดับ/เติมคำ, ม.3 เติมคำ) ใช้คะแนนเท่าข้อปรนัย
- หน้าเฉลยแสดงทั้งคะแนนรวมและจำนวนข้อที่ถูก ชีต Attempts เก็บ `score` และ `maxScore` เพิ่ม

- **ข้อ "นอกหลักสูตรปัจจุบัน"** = ข้อที่เว้นคอลัมน์ตัวชี้วัดว่าง (เนื้อหาไม่อยู่ในตัวชี้วัดฉบับปรับปรุง 2560 ของระดับนั้น ปัจจุบัน 28 ข้อของปี 2561–2562) หน้าเว็บคงไว้ในโหมดข้อสอบรายปีพร้อมป้าย "นอกหลักสูตรปัจจุบัน" แต่ไม่นำไปใช้ในโหมดฝึกรายมาตรฐาน ข้อสอบจำลอง และไม่นับในตารางผัง/ตารางสรุป · ทดสอบด้วย `node tools/test/outcurr.mjs` (เปิด server ค้างไว้)
## โหมดข้อสอบและสรุปเนื้อหา
- **โหมดข้อสอบรายปี** แสดงผลเป็นร้อยละและจำนวนข้อที่ถูก ไม่แสดงคะแนนเต็ม (ฉบับก่อน 2564 มีจำนวนข้อ/คะแนนต่างจากผัง 2569 ทำให้คะแนนเต็มไม่ใช่ 100) · โหมดข้อสอบจำลองตามผังยังแสดงคะแนนตามผัง 2569 · ข้อเชิงซ้อนยังคิดคะแนนบางส่วนตามเกณฑ์ใน `PARTIAL` แล้วนำมารวมเป็นร้อยละ
- **ข้อสอบจริงแยกรายปี**: ทำทั้งฉบับของปีนั้นตามเลขข้อ
- **แยกตามมาตรฐาน/ตัวชี้วัด**: ข้อสอบชุดเดียวกัน จัดกลุ่มใหม่ตามคอลัมน์ มาตรฐาน/ตัวชี้วัด ที่กรอกตอนนำเข้า (ไม่ต้องนำเข้าซ้ำ)
- **สรุปก่อนฝึก**: ชีต `Summaries` (`level | standard | indicator | title | content`) มีสรุปตั้งต้นรายมาตรฐาน 16 หัวข้อ
  เพิ่มแถวที่ใส่ `indicator` (เช่น ป.6/1) เพื่อทำสรุปรายตัวชี้วัด ขึ้นบรรทัดใหม่ในเซลล์ด้วย Alt+Enter
  หน้าสรุปจะแสดงตารางว่าหัวข้อนั้นเคยออกข้อสอบปีไหน กี่ข้อ โดยนับจากคลังข้อสอบอัตโนมัติ
- ถ้าเคยรัน `setup` ไปแล้ว ให้วาง `Code.gs` ใหม่ รัน `setup` อีกครั้ง (จะเพิ่มชีตและหัวคอลัมน์ใหม่ เช่น `Questions.type`, `Attempts.score/maxScore` โดยไม่แตะข้อมูลเดิม) แล้ว Deploy เป็น New version

## สรุปเนื้อหา (ไฟล์ `data/summaries/`)
สรุปเก็บเป็นไฟล์ข้อความ หนึ่งไฟล์ต่อ **ระดับ + มาตรฐาน** ตั้งชื่อ `<ระดับ>-<มาตรฐาน>.txt` เช่น `P6-2.1.txt` · ป.6 กับ ม.3 แยกไฟล์ แยกภาพ ไม่ใช้เนื้อหาร่วมกัน
**โครงสร้างไฟล์**: บรรทัดที่ขึ้นต้น `//` ก่อนหัวข้อแรกเป็นหมายเหตุ · แต่ละตัวชี้วัดขึ้นต้นด้วยบรรทัดหัวข้อ `@@ ระดับ | มาตรฐาน | ตัวชี้วัด | ชื่อหัวข้อ` ตามด้วยเนื้อหา · เรียงตัวชี้วัดจากที่ข้อสอบ 2561–2568 ออกบ่อยสุด ตัวที่ไม่เคยออกอยู่ท้ายไฟล์และสั้นกว่า · หน้าเว็บแสดงตามลำดับในไฟล์ (หนึ่งมาตรฐาน = หนึ่งหน้า กด "สรุป + ฝึก" ที่มาตรฐาน)
**นำเข้า**: เข้าสู่ระบบผู้ดูแลกลาง → แท็บ "สรุปเนื้อหา" → เลือกไฟล์ `data/summaries/<ไฟล์>.txt` → นำเข้า (ครั้งละไฟล์) สรุปเดิมของมาตรฐานนั้น (ระดับ+มาตรฐานเดียวกัน) จะถูกแทนที่ทั้งหมด มาตรฐานอื่นคงไว้ · ข้อมูลเก็บในชีต `Summaries` (level | standard | indicator | title | content)

## ข้อจำกัด
- นักเรียนเข้าด้วยรหัสห้องเรียน 6 ตัว (สุ่ม แยกตามโรงเรียน+ระดับ+ห้อง) แล้วเลือกชื่อ ไม่มีรหัสผ่านรายคน จึงเข้าแทนเพื่อนในห้องเดียวกันได้ · API ที่คืนรายชื่อหรือผลของนักเรียนต้องมีรหัสห้องหรือ token แอดมิน · ไม่มีรายชื่อโรงเรียนแบบเปิด · ครูกด "สร้างรหัสใหม่" ได้เมื่อรหัสหลุด (รหัสเดิมใช้ไม่ได้ทันที) · หลังอัปเดตโค้ดต้องรัน setup() ใหม่หนึ่งครั้งเพื่อสร้างชีต Rooms · ทดสอบด้วย `node tools/test/privacy.mjs`
- ข้อจับคู่ยังไม่มีชนิดเฉพาะ ต้องใช้ `fill` (พิมพ์คำตอบให้ตรงเฉลย)
- Apps Script รองรับผู้ใช้พร้อมกันราว 30 คน ถ้าทั้งห้องกดพร้อมกันอาจช้า

ข้อสอบและผังข้อสอบเป็นของสถาบันทดสอบทางการศึกษาแห่งชาติ (สทศ.) https://www.niets.or.th

### หมายเหตุการเขียนสรุปเนื้อหา
- ห้ามใช้อักขระลูกศรทับตัวอักษร (เช่น v + U+20D7) ใน SVG/ข้อความ เพราะ PDF แสดงเป็นกล่องว่าง ให้เขียนเป็นคำ
- สรุปเนื้อหาทุกมาตรฐาน (P6 และ M3) ตรวจแล้ว: ครบรายข้อ (coverage-*.tsv) · หน้าสรุปย่อ 1 หน้า · PDF ไม่ตัดภาพ/ตาราง/สมการ · รายการที่ต้องให้ครูตรวจอยู่ใน data/REVIEW.md หมวด "สรุปเนื้อหา"



## เฉลยละเอียด (ต้นแบบปี 2568)
- ไฟล์: `data/solutions/<P6|M3>-<ปี>.txt` บล็อกละข้อ เริ่มด้วย `@@ ระดับ | ปี | ข้อ | มาตรฐาน | ตัวชี้วัด | ชื่อ` ใช้ markup เดียวกับสรุปเนื้อหา เพิ่ม `xx:` (จุดที่มักพลาด) `ob:` (ข้อสังเกต ต้องมีบรรทัด `- **M3-2568 ข้อ 8** …` ในหัวข้อ "# เฉลยละเอียด" ของ `data/REVIEW.md`) และ `>> มาตรฐาน | ตัวชี้วัด | หัวข้อ` (ลิงก์ไปสรุปเนื้อหา)
- นำเข้า: แอดมินเรียก action `importSolutions` (เหมือน importSummaries) · หน้าเว็บดึงด้วย action `solutions` · หน้าตรวจคำตอบแสดงคำอธิบายสั้นก่อน มีปุ่ม "ดูเฉลยละเอียด" · พิมพ์ PDF จะรวมเฉลยละเอียดทุกข้อ
- ตรวจไฟล์: `node tools/solutions.mjs`
- PDF ให้ครูตรวจ: `node tools/review-pdf.mjs P6 2568` · `node tools/review-pdf.mjs M3 2568 --extra M3-2564/28,M3-2561/38,M3-2563/28` → `review/REVIEW-<ระดับ>-<ปี>.pdf`
- ภาพมือถือ: `node tools/mobile-shots.mjs M3 2568 8` (ต้องรัน `tools/test/server.mjs` ก่อน)
