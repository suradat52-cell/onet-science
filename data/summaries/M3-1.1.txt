## สายใยอาหาร: ผู้ผลิต ผู้บริโภค และลำดับ
[[fig:m3-foodweb-ex|สายใยอาหารตัวอย่าง ลูกศรชี้ไปยังผู้กิน]]
kc: **โซ่อาหาร** = ทางเดียวของการกิน (หญ้า → หนู → งู → เหยี่ยว) · **สายใยอาหาร** = หลายโซ่เชื่อมกัน
• **ผู้ผลิต** อยู่ต้น (หญ้า) · **ผู้บริโภคลำดับ 1** กินผู้ผลิต · ลำดับ 2 กินลำดับ 1 · ลำดับ 3 กินลำดับ 2
• สัตว์ที่กินสัตว์หลายลำดับ เป็น **ผู้บริโภคได้หลายลำดับ** (ในรูป งู กินหนู = ลำดับ 2 และกินกบ = ลำดับ 3)
• **ผู้ย่อยสลาย** ย่อยซากของทุกลำดับ แล้วคืนสารเข้าระบบนิเวศ
ex: ในรูป นับโซ่อาหารจากหญ้าถึงเหยี่ยว: ① หญ้า → ตั๊กแตน → นกกินแมลง → เหยี่ยว ② หญ้า → ตั๊กแตน → กบ → งู → เหยี่ยว ③ หญ้า → หนู → งู → เหยี่ยว → **3 โซ่**
ex: ผู้บริโภคลำดับสุดท้ายในสายใยนี้ = เหยี่ยว · เหยี่ยวไม่มีผู้ล่าในรูป · งู และ กบ เป็นทั้งเหยื่อ (ถูกกิน) และผู้ล่า
ex: ถ้าตัดตั๊กแตนออกจากสายใย → กบ และนกกินแมลง ยังมีอาหารอื่นหรือไม่? ในรูปทั้งสองกินตั๊กแตนอย่างเดียว → ได้รับผลกระทบมาก · ส่วนงูยังกินหนูได้ → ได้รับผลน้อยกว่า
?? โจทย์ถูก/ผิดเกี่ยวกับลำดับ: ตรวจว่าสัตว์กินผู้ผลิตโดยตรง = **ลำดับ 1** (กวางที่กินหญ้าเป็นลำดับ 1 ไม่ใช่ลำดับ 2)
?? โจทย์นับโซ่อาหาร: ไล่ตามลูกศรทุกเส้นทางจากผู้ผลิตจนถึงผู้บริโภคสุดท้าย (อย่าลืมโซ่ที่ต่างกันเพียงชนิดเดียว)
?? โจทย์ "ได้รับผลมากกว่า": สัตว์ที่มี **แหล่งอาหารทางเดียว** ได้รับผลมากกว่าสัตว์ที่มีแหล่งอาหารหลายอย่าง
## การถ่ายทอดพลังงานในสายใยอาหาร
[[fig:m3-energy-pyramid|พีระมิดพลังงาน ผู้ผลิตมากที่สุด ผู้บริโภคสุดท้ายน้อยที่สุด]]
• พลังงานเริ่มจากแสงอาทิตย์ ถูกผู้ผลิตเก็บไว้ แล้วถ่ายทอดตามการกิน
• พลังงานส่งต่อผ่านการกินได้เพียง ≈ **10%** ต่อลำดับ (ที่เหลือกลายเป็นความร้อนและถูกใช้เอง)
• ผลคือ **ผู้ผลิตมีพลังงานมากที่สุด** · ผู้บริโภคลำดับสูง พลังงานน้อยลงเรื่อย ๆ · ผู้บริโภคสุดท้าย **น้อยที่สุด**
ex: ผู้ผลิตมีพลังงาน 50,000 kJ → ผู้บริโภค 1 ≈ 5,000 → ผู้บริโภค 2 ≈ 500 → ผู้บริโภค 3 ≈ 50 kJ
ex: ระบุลำดับผู้บริโภคของโซ่ "หญ้า
th: ตั๊กแตน
th: กบ
th: งู": ลำดับ 1 = ตั๊กแตน · 2 = กบ · 3 = งู
an: งู ได้พลังงานน้อยกว่ากบ (ประมาณ {1/10})
ex: เรียงพลังงานสะสม **น้อย → มาก** ของ 3 ชนิดในโซ่ "หญ้า → ตั๊กแตน → กบ → งู": งู → กบ → ตั๊กแตน (หญ้ามากที่สุด)
?? โจทย์ "ข้อใดถูกต้อง": **เหยี่ยว (ลำดับสูง) ได้พลังงานน้อยกว่าสัตว์ลำดับต่ำ**
?? "ผู้ผลิตมีพลังงานสะสมมากสุด" ถูก
?? โจทย์ถามเรียงลำดับพลังงานตามลำดับผู้บริโภค: เริ่มที่ผู้บริโภคสุดท้าย (น้อยสุด) ไล่ไปหาผู้ผลิต
## ผลเมื่อประชากรเปลี่ยน และการควบคุมโดยชีววิธี
kc: เมื่อ **ผู้ล่าลดลง** → เหยื่อ **เพิ่มขึ้น** → อาหารของเหยื่อ (เช่น พืช) **ลดลง**
• เมื่อ **เหยื่อลดลง** → ผู้ล่าที่พึ่งเหยื่อชนิดเดียว **ลดลง**
• **ชีววิธี** = ใช้ผู้ล่าตามธรรมชาติควบคุมศัตรูพืช (เช่น ด้วงเต่ากินเพลี้ย) แทนสารเคมี
ex: ในสายใยตัวอย่าง ถ้ามีคนล่านกกินแมลงจนเกือบหมด → ตั๊กแตนมีผู้ล่าน้อยลงจึงเพิ่ม → หญ้าถูกกินมากขึ้น → หญ้าลดลง · กบอาจเหลืออาหารน้อยลง ถ้าตั๊กแตนเพิ่มเกิน (แข่งขันกัน)
ex: ฟาร์มพืชถูกหนอนทำลาย เกษตรกรปล่อยแตนเบียนที่วางไข่ในหนอน → หนอนลดลง ผลผลิตเพิ่ม โดยไม่ใช้ยาฆ่าแมลง → เป็นชีววิธี
ex: เพลี้ยอ่อนทำให้ต้นข้าวโพดตายนาน → ผู้ผลิตลดลง → สัตว์กินข้าวโพด (หนู นกกินพืช) ลดลงตาม → เหยี่ยวที่กินพวกมันก็ลดลงเมื่อเวลานานพอ
?? โจทย์ "ฉีดยาฆ่าแมลง": ตัวที่สะสมสารพิษมากสุดคือ **ผู้บริโภคปลายสายใย** (ไม่ใช่ผู้ผลิต)
?? โจทย์ "ถ้าผู้ล่าเพิ่ม ผลผลิตข้าวเป็นอย่างไร": ผู้ล่าเพิ่ม → สัตว์ที่กินข้าวลด → **ข้าวเหลือมากขึ้น**
?? โจทย์ "ใช้ผู้ล่ากำจัดศัตรูพืช": เป็น **ชีววิธี** ถ้าผู้ล่ากินศัตรูพืชโดยตรง

## สารพิษสะสมในโซ่อาหาร
[[fig:m3-biomagnification|ความเข้มข้นสารพิษเพิ่มตามลำดับการกิน]]
kc: สารพิษที่ **สลายยาก/ขับออกยาก** (เช่น DDT แคดเมียม ปรอท) ถูกสะสมในร่างกาย
• สัตว์กินสัตว์ ทำให้สารพิษ **สะสมเพิ่มทวีคูณ** ในแต่ละลำดับ · **ผู้บริโภคลำดับสุดท้ายเข้มข้นที่สุด**
• เมื่อสารเคมีตกค้างในดิน พืชดูดสู่ราก → ผ่านเข้าสู่โซ่อาหาร
ex: โรงงานปล่อยปรอทลงแม่น้ำ มีโซ่อาหาร: สาหร่าย → กุ้งฝอย → ปลาเล็ก → ปลาช่อน → นกกินปลา → นกกินปลามีปรอทเข้มข้นมากที่สุด (ลำดับสุดท้าย) ไม่ใช่สาหร่าย (ผู้ผลิต)
ex: ชาวบ้านใช้สารเคมีเกษตรมานาน แล้วเลิกใช้ แต่ยังตกค้างในดิน ต้องการเลี่ยงการถ่ายทอดสู่สัตว์และคน → ปลูกพืชที่ **ไม่เข้าสู่ห่วงโซ่อาหาร** เช่น พืชพลังงานเพื่อผลิตเชื้อเพลิง (ไม่ใช่พืชอาหารคนหรืออาหารสัตว์)
ex: เปรียบเทียบความเข้มข้น: น้ำ 1 หน่วย แพลงก์ตอน 10 ปลาเล็ก 100 ปลาใหญ่ 1,000 → ปลาใหญ่มีความเข้มข้นของสารพิษ 1,000 เท่าของน้ำ
?? โจทย์ "สิ่งมีชีวิตใดสะสมสารพิษมากที่สุด": **ผู้บริโภคลำดับสุดท้ายในสายใยอาหารที่โจทย์ให้**
?? โจทย์ "เลือกปลูกพืชเพื่อไม่ถ่ายทอดสารเคมี": ตัดตัวเลือกที่เป็นอาหารคน/สัตว์ เหลือ **พืชใช้ผลิตเชื้อเพลิง**

| ทิ้งลงแหล่งน้ำ | น้ำเน่าเสีย ออกซิเจนในน้ำลด สัตว์น้ำตาย |

?? โจทย์ "ข้อใดไม่ใช่ปัญหาจากวิธีกำจัดขยะที่ให้": ตัดปัญหาที่ **เกิดจากวิธีที่ระบุ** (น้ำเสีย ดินเสื่อม) เหลือปัญหาจากการ **เผา** เช่น PM 2.5

## วัฏจักรคาร์บอนและออกซิเจน
[[fig:m3-carbon-cycle|วัฏจักรคาร์บอน: ก ข ค ง]]
kc: **สังเคราะห์ด้วยแสง** (พืช): **ใช้ CO₂ ปล่อย O₂** → ลด CO₂ ในอากาศ เพิ่ม O₂
• **หายใจ** (พืช สัตว์ ผู้ย่อยสลาย): **ใช้ O₂ ปล่อย CO₂** → เพิ่ม CO₂ ลด O₂
• **ย่อยสลาย** (ผู้ย่อยสลาย): ปล่อย CO₂ · **เผาเชื้อเพลิง/ไฟป่า**: ปล่อย CO₂
• ตัดไม้ทำลายป่า → สังเคราะห์ด้วยแสงลดลง → CO₂ ในอากาศ **เพิ่มขึ้น**
ex: แผนภาพวัฏจักรสาร X: กระบวนการ P คือพืชรับ X จากอากาศแล้วปล่อยแก๊สอีกชนิด · กระบวนการ Q คือสัตว์และผู้ย่อยสลายปล่อย X กลับอากาศ → X = CO₂ · P = สังเคราะห์ด้วยแสง · Q = หายใจและย่อยสลาย → ถ้า Q เพิ่ม X ในอากาศเพิ่ม · ถ้า P ลด X เพิ่ม และ O₂ ลด
ex: ป่าถูกเผาเป็นบริเวณกว้าง → ต้นไม้ลดลง (P ลด) และเกิดการเผาไหม้ (ปล่อย CO₂) → CO₂ เพิ่มมาก · O₂ ลด
ex: ถ้าหายใจเพิ่ม (กิจกรรมสัตว์เพิ่ม) แต่พืชเท่าเดิม → CO₂ เพิ่ม O₂ ลด เล็กน้อย

## ผู้ย่อยสลายกับการหมุนเวียนสาร
kc: **ผู้ย่อยสลาย** (เห็ด รา แบคทีเรีย) ย่อยซากพืชซากสัตว์ → ได้สารอนินทรีย์คืนสู่ดิน น้ำ อากาศ → พืชนำไปใช้
• ถ้าไม่มีผู้ย่อยสลาย ซากจะสะสม และสารอาหารจะหมดไปจากระบบ
ex: เห็ดย่อยใบไม้ร่วง → ได้ไนโตรเจน ฟอสฟอรัส คืนสู่ดิน → พืชดูดไปใช้สร้างใบใหม่

## ผลของการเปลี่ยนแปลงจำนวนผู้ล่าและเหยื่อ
kc: องค์ประกอบ: **สิ่งไม่มีชีวิต** (แสง น้ำ อุณหภูมิ ดิน) + **สิ่งมีชีวิต** (ผู้ผลิต ผู้บริโภค ผู้ย่อยสลาย) ทำงานร่วมกัน
• เมื่อมนุษย์จับผู้ล่ามาก (เช่น งู) → เหยื่อ (หนู) **เพิ่ม** → พืชถูกกินมากขึ้น
ex: ชาวบ้านจับกบขายจำนวนมาก → กบลดลง · แมลงที่กบกิน เพิ่มขึ้น · งูที่กินกบ ลดลงหรือหันไปกินสัตว์อื่น → ระบบเสียสมดุล
ex: ถ้าตัวเลือกบอกว่า "ข้าวให้ผลผลิตมากขึ้น" หลังจับงู → ไม่น่าเป็นไปได้ (หนูเพิ่ม ข้าวถูกกินมากขึ้น)
?? โจทย์ "จับผู้ล่าออกมาก สถานการณ์ใดเป็นไปได้มากที่สุด": **เหยื่อของผู้ล่านั้นเพิ่มขึ้น**
## ความสัมพันธ์ระหว่างสิ่งมีชีวิตในระบบนิเวศ
| ภาวะ | ตัวอย่าง | ผลต่อสองฝ่าย |
| **การล่า** | งูกินหนู | ผู้ล่า + · เหยื่อ − |
| **แข่งขัน** | ลิงกับนกแย่งอาหาร | ทั้งสอง − |
| **พึ่งพากัน** | ผึ้งกับดอกไม้ | ทั้งสอง + |
| **อาศัย** | เหาฉลามกับฉลาม | ฝ่ายหนึ่ง + · อีกฝ่าย 0 |
| **ปรสิต** | เห็บกับสุนัข | ปรสิต + · เจ้าบ้าน − |
!! + = ได้ประโยชน์ · − = เสียประโยชน์ · 0 = ไม่ได้ไม่เสีย
kc: **ภาวะการล่า**: ผู้ล่าได้ประโยชน์ เหยื่อเสีย
kc: **ภาวะแข่งขัน**: แย่งอาหาร/ที่อยู่ เสียทั้งคู่
kc: **ภาวะพึ่งพากัน**: ได้ประโยชน์ทั้งคู่ (ผึ้งกับดอกไม้)
kc: **ภาวะอาศัย**: ฝ่ายหนึ่งได้ อีกฝ่ายไม่ได้ไม่เสีย · **ภาวะปรสิต**: ปรสิตได้ เจ้าบ้านเสีย
ex: ลิงแสมกับนกที่แย่งผลไม้กัน = **แข่งขัน** · ไม่ใช่ พึ่งพากัน
ex: ปลาตัวเล็กตามกินเศษอาหารของปลาฉลาม โดยฉลามไม่เสียหาย = **อาศัย**
ex: เห็บดูดเลือดสุนัข = **ปรสิต** · ผึ้งกับดอกไม้ = **พึ่งพากัน**
?? โจทย์ "ความสัมพันธ์แบบใด": ดูว่า **ใครได้ ใครเสีย** แล้วเทียบตาราง
