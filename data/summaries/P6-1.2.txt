## ระบบย่อยอาหาร (ออกบ่อยที่สุด)
| อวัยวะ | ทำอะไร |
| ปาก | บดเคี้ยว · น้ำลายย่อย **แป้ง** เป็นน้ำตาล |
| กระเพาะอาหาร | กรด + เอนไซม์ เริ่มย่อย **โปรตีน** |
| ตับ | สร้าง **น้ำดี** ช่วยให้ไขมันแตกตัว (ไม่ใช่น้ำย่อย) |
| ตับอ่อน | สร้าง **เอนไซม์** ย่อยแป้ง โปรตีน ไขมัน ส่งไปลำไส้เล็ก |
| ลำไส้เล็ก | ย่อยให้เสร็จ · **ดูดซึมสารอาหาร** เข้าหลอดเลือด (ส่วนใหญ่) |
| ลำไส้ใหญ่ | **ไม่ย่อยอาหาร** · ดูดน้ำและเกลือแร่ · เหลือเป็นกาก |
!! ปอดไม่ใช่ระบบย่อยอาหาร · เลือดที่ไหลจากหัวใจไปเลี้ยงอวัยวะ (รวมลำไส้ใหญ่) มี **ออกซิเจนสูง** เพราะมาจากปอด
## พืชดอก และสารอาหาร
| ส่วนของพืช | หน้าที่ |
| ราก | ดูดน้ำและแร่ธาตุ · ยึดลำต้น (ไม่มีข้อ ปล้อง ตา ปากใบ) |
| ลำต้น | ลำเลียงน้ำและอาหาร · ชูใบ (มีข้อ ปล้อง ตา) |
| ใบ | สร้างอาหาร · คายน้ำทางปากใบ |
| ดอก | สืบพันธุ์ สร้างเมล็ดและผล |
| ไอโอดีน | น้ำเงินเข้ม = **แป้ง** · กระดาษ รอยโปร่งแสง = **ไขมัน** |
!! สังเคราะห์ด้วยแสง: แสง + น้ำ + CO₂ → **น้ำตาล + O₂** (น้ำกับ CO₂ เป็นวัตถุดิบ ไม่ใช่ผลผลิต) · หยดน้ำในถุงที่ครอบพืช = **คายน้ำ** (ไม่ใช่หายใจ)

## อวัยวะในระบบย่อยอาหารและหน้าที่
[[fig:p6-digest-system|อวัยวะในระบบย่อยอาหารและหน้าที่]]
• อาหารต้องถูก **ย่อย** ให้เป็นชิ้นเล็กมากก่อน จึง **ดูดซึม** ผ่านผนังลำไส้เข้าเลือดได้
• **ปาก**: ฟันบดเคี้ยว (ย่อยทางกล) · เอนไซม์ในน้ำลายเปลี่ยน **แป้ง** ให้เป็นน้ำตาล
• **หลอดอาหาร**: ลำเลียงอาหารลงกระเพาะ (ไม่ย่อย ไม่ดูดซึม)
• **กระเพาะอาหาร**: ผนังบีบนวด · กรดและเอนไซม์ เริ่มย่อย **โปรตีน**
• **ตับ**: สร้าง **น้ำดี** ช่วยให้ไขมันแตกเป็นหยดเล็ก (ไม่ใช่เอนไซม์)
• **ตับอ่อน**: สร้าง **เอนไซม์** ส่งมาที่ลำไส้เล็ก ย่อยแป้ง โปรตีน ไขมัน
• **ลำไส้เล็ก**: ย่อยให้เสร็จ · **ดูดซึมสารอาหาร** เกือบทั้งหมด
• **ลำไส้ใหญ่**: ดูดน้ำและเกลือแร่ · เหลือกาก → ทวารหนัก (ไม่ย่อยอาหาร)
!! จำคู่: ตับ = น้ำดี (น้ำดีไม่มีเอนไซม์) · กรดอยู่ที่ **กระเพาะอาหาร** · ลำไส้ใหญ่ **ไม่ดูดซึมสารอาหารทุกประเภท**
## ย่อยที่ไหน ดูดซึมที่ไหน
[[fig:p6-digest-where|แป้ง โปรตีน ไขมัน เริ่มย่อยและย่อยจนเสร็จที่ใด]]
• แป้ง: เริ่มที่ **ปาก** → ย่อยจนเสร็จที่ **ลำไส้เล็ก**
• โปรตีน: เริ่มที่ **กระเพาะอาหาร** → ย่อยจนเสร็จที่ **ลำไส้เล็ก**
• ไขมัน: ย่อยที่ **ลำไส้เล็ก** (ใช้น้ำดีจากตับ + เอนไซม์จากตับอ่อน)
• สารอาหารที่ย่อยแล้วดูดซึมที่ **ลำไส้เล็ก** เป็นส่วนใหญ่
ex: กินขนมปังทาเนยถั่ว (ขนมปังเป็นแป้ง เนยถั่วมีโปรตีนและไขมัน) → แป้งเริ่มย่อยที่ปาก · โปรตีนเริ่มที่กระเพาะ · ไขมันย่อยที่ลำไส้เล็ก · ทั้งหมดดูดซึมที่ลำไส้เล็ก
ex: กินสลัดผักกับไก่ย่าง (ผัก = ใยอาหารเป็นส่วนใหญ่ ไก่ = โปรตีน) → ไก่เริ่มย่อยที่กระเพาะ ใยอาหารไม่ถูกย่อย ผ่านลำไส้ใหญ่ออกมาเป็นกาก
ex: ถ้าตับสร้างน้ำดีไม่ได้ → ไขมันแตกเป็นหยดเล็กไม่ดี → ย่อยไขมันที่ลำไส้เล็กได้ช้าลง · แป้งและโปรตีนยังย่อยได้ปกติ
ex: ถ้าตัดลำไส้ใหญ่ออก → การย่อยอาหารยังเกือบปกติ (ไม่ได้ย่อยที่นี่) แต่ดูดน้ำกลับคืนได้น้อยลง ทำให้อุจจาระเหลว
ex: ถาม "สารอาหารถูกดูดซึมมากที่สุดที่ใด" → ลำไส้เล็ก (ตับอ่อนสร้างน้ำย่อย ไม่ได้ดูดซึม · กระเพาะดูดซึมน้อยมาก)
?? โจทย์ให้ภาพอวัยวะ A–E แล้วถามที่ย่อยของอาหารต่าง ๆ: หา **ตำแหน่ง** ปาก กระเพาะ ลำไส้เล็ก ลำไส้ใหญ่ ก่อน แล้วตอบตามตาราง
?? โจทย์ "ตับหรือตับอ่อนสร้างอะไร": ตับ → น้ำดี (ช่วยไขมัน) · ตับอ่อน → เอนไซม์ย่อยอาหาร
?? โจทย์ข้อความ ใช่/ไม่ใช่: "ดูดซึมสารอาหารทั้งหมดที่ลำไส้ใหญ่" ไม่ใช่ · "เริ่มย่อยโปรตีนที่กระเพาะ" ใช่ · "แป้งเริ่มย่อยที่ปาก" ใช่
## การทำงานร่วมกับระบบหายใจและระบบหมุนเวียนเลือด
[[fig:p6-blood-loop|เลือดไหลระหว่างปอด หัวใจ และอวัยวะต่าง ๆ]]
• ลำไส้ดูดซึมสารอาหารเข้าเลือด · ปอดนำ O₂ เข้าเลือด · เลือดนำสารอาหารและ O₂ ไปเซลล์ → เซลล์ **สลายอาหาร** ได้พลังงาน และได้ CO₂ ส่งกลับไปปอด
• เลือดที่ออกจากหัวใจไปเลี้ยงอวัยวะ มี **O₂ สูง** (เพราะผ่านปอดมาแล้ว) · เลือดที่กลับจากอวัยวะที่ใช้พลังงานมี **CO₂ สูง**
ex: ถ้าปอดทำงานได้ลดลงมาก → O₂ เข้าเลือดน้อยลง → หัวใจสูบฉีดบ่อยขึ้น · เซลล์สลายอาหารเป็นพลังงานลดลง · CO₂ ออกจากเลือดสู่ปอดน้อยลง
ex: เลือดจากลำไส้เล็กกลับเข้าหัวใจ มี CO₂ **สูง** เพราะเซลล์ลำไส้ใช้อาหารสร้างพลังงานแล้วปล่อย CO₂ (ไม่ใช่ต่ำ)
?? โจทย์ "เมื่อปอดบกพร่อง สิ่งใดไม่เกิดขึ้น": ตัวเลือกที่ว่า CO₂ ออกจากเลือดไปปอด **เพิ่มขึ้น** ผิด (ต้องลดลง)
?? โจทย์ถามเลือดจากหัวใจไปยังอวัยวะต่าง ๆ: O₂ **สูง** (ผ่านปอดแล้ว) · จากอวัยวะกลับหัวใจ: CO₂ **สูง**

## ส่วนต่าง ๆ ของพืชดอก และสังเคราะห์ด้วยแสง
[[fig:p6-plant-parts|ราก ลำต้น ใบ ดอก และหน้าที่]]
• **ราก** ดูดน้ำและแร่ธาตุ ยึดต้นไม้ · ไม่มีข้อ ปล้อง ตา ปากใบ
• **ลำต้น** ลำเลียงน้ำและอาหาร ชูใบให้รับแสง · มี **ข้อ ปล้อง ตา**
• **ใบ** สร้างอาหาร (สังเคราะห์ด้วยแสง) · มี **ปากใบ** คายน้ำ · สีเขียว
• **ดอก** ใช้สืบพันธุ์ สร้างเมล็ดและผล
[[fig:p6-photosynthesis|แสง น้ำ CO₂ → น้ำตาล และ O₂]]
• **สังเคราะห์ด้วยแสง**: วัตถุดิบ แสง น้ำ และ CO₂ → ใบได้ **น้ำตาล** เป็นอาหาร และคายแก๊ส **ออกซิเจน** ออกมา
• ใบมาก = สังเคราะห์ด้วยแสงมาก → ดูด CO₂ มาก · สร้างน้ำตาลมาก · ปล่อย O₂ มาก
ex: ตัดส่วนของพืช 3 ส่วนใส่ภาชนะ X Y Z: X เขียว มีปากใบ · Y มีข้อปล้องและตา · Z สีขาว ไม่มีข้อปล้อง ตา ปากใบ → X = ใบ (คายน้ำ) · Y = ลำต้น · Z = ราก (ดูดน้ำ)
ex: ต้นไม้ต้นหนึ่งแตกกิ่งใบหนาแน่นด้านซ้าย ด้านขวาเบาบาง → ด้านซ้ายสังเคราะห์ด้วยแสงมากกว่า: ดูด CO₂ มากกว่า สร้างน้ำตาลมากกว่า ปล่อย O₂ มากกว่า
ex: ถามว่า "สังเคราะห์ด้วยแสงสร้างสารใดที่สำคัญต่อคนและสัตว์" → **น้ำตาล และออกซิเจน** (น้ำ กับ CO₂ เป็นวัตถุดิบ ไม่ใช่ผลผลิต)
?? โจทย์ให้ตารางลักษณะภายนอก + ผลทดสอบแป้ง ของภาชนะ A B C: ใบ = เขียว มีปากใบ · ลำต้น = มีข้อปล้อง ตา · ราก = ไม่มีทั้งหมดนั้น
?? โจทย์ถาม "ส่วนที่คายน้ำ" → ใบ (ปากใบ) · "ส่วนที่ดูดน้ำ" → ราก
## การคายน้ำ และการออกแบบการทดลอง
[[fig:p6-bag-transpire|ต้นไม้ในถุงพลาสติก มีหยดน้ำที่ผิวด้านในถุง]]
• **คายน้ำ** = ใบปล่อยไอน้ำออกทางปากใบ · พืชที่ตายแล้วไม่คายน้ำ · ต้องมีชีวิต และมีรากส่งน้ำจากดินขึ้นมาให้ใบ
• หยดน้ำในถุงที่ครอบพืชมาจาก **การคายน้ำ** (ไม่ใช่การหายใจ)
• การทดลอง **เปรียบเทียบผลของแสง**: เลือกสองชุดที่ต่างกัน **เฉพาะแสง** (ชุดหนึ่งมีแสง อีกชุดมืด) ตัวแปรอื่น (ถุง ขนาดต้น อายุ) ต้องเหมือนกัน
ex: ต้นกุหลาบสองต้นอายุเท่ากัน ใส่ถุงใสเหมือนกัน ชุด 1 วางกลางแจ้ง ชุด 2 วางในที่มืด ชุด 3 ไม่คลุมถุง วางกลางแจ้ง → เปรียบเทียบผลของแสงได้ที่ชุด 1 กับ 2 (ต่างกันที่แสงอย่างเดียว) · ชุด 1 กับ 3 ต่างกันที่ถุงด้วย จึงไม่ใช่
ex: ซื้อต้นไม้แล้วเอาใส่ถุงมัดปาก พอถึงบ้านมีหยดน้ำเกาะด้านในถุง → ใช่: ต้นไม้ยังมีชีวิต และดูดน้ำได้ · ไม่ใช่: หยดน้ำมาจากการหายใจ
ex: ต้นไม้ในถุงชุด 1 วางที่ร้อนจัด ชุด 2 วางที่เย็น → ถ้าเทียบผลของอุณหภูมิต่อการคายน้ำ ต้องคงแสง ถุง ขนาดต้นให้เหมือนกัน
?? โจทย์จัดชุดการทดลองจากตาราง 4 ชุด: ดูว่าคู่ใด **ต่างกันตัวแปรเดียวคือสิ่งที่ถาม**
?? โจทย์ถุงครอบต้นไม้: หยดน้ำ = คายน้ำ → พืชมีชีวิต ดูดน้ำได้ · ไม่ใช่หายใจ
## ลำต้นใต้ดิน และการผสมเกสร
[[fig:p6-tuber-root|หัวที่มีตาเป็นลำต้นใต้ดิน ส่วนรากสะสมอาหารไม่มีตา]]
• **ตา** พบเฉพาะบน **ลำต้น** · หัวใต้ดินที่มีตาและงอกยอดได้ = **ลำต้นใต้ดิน** (เช่น มันฝรั่ง ขิง ข่า) → ใช้ **ขยายพันธุ์** ได้
• **รากสะสมอาหาร** (เช่น มันเทศ แครอท) ไม่มีตา ไม่มีข้อปล้อง
• **ดอกสมบูรณ์เพศ**: มีเกสรเพศผู้และเพศเมียในดอกเดียวกัน · **ดอกไม่สมบูรณ์เพศ**: มีเพศใดเพศหนึ่ง
[[fig:p6-flower-timeline|ดูช่วงเวลาที่ดอกเพศผู้และเพศเมียบานพร้อมกัน]]
• ช่วยผสมเกสรได้เมื่อดอกเพศผู้และเพศเมียที่ต้องการ **พร้อมพร้อมกัน** (ช่วงที่ซ้อนกัน)
ex: หัวใต้ดินของพืชชนิดหนึ่ง มีรอยตาเล็ก ๆ ไม่มีข้อปล้อง เมื่อวางในที่ชื้น มียอดอ่อนงอกจากตา → ตัดสินว่า เป็นลำต้นใต้ดิน (มีตา) · ไม่ใช่รากสะสมอาหาร · ใช้ขยายพันธุ์ได้
ex: ต้นฟักทองมีดอกแยกเพศบนต้นเดียวกัน: เมล็ดงอกเป็นต้นโตใช้เวลา 20 วัน · ดอกเพศผู้พร้อมวันที่ 30 บานได้ 6 วัน (30–36) · ดอกเพศเมียพร้อมวันที่ 34 บานได้ 10 วัน (34–44) → ช่วงที่ทั้งคู่พร้อม = 34–36 → ต้องช่วยผสมเกสรตั้งแต่ **วันที่ 34** (รอดอกเพศเมียพร้อมก่อน)
ex: ต้นพืชหนึ่ง ดอกเพศผู้บานวัน 12–15 ดอกเพศเมียบานวัน 20–26 → ไม่มีช่วงซ้อนกัน → ผสมกันเองในต้นเดียวกันไม่ได้ ต้องเก็บเกสรไว้ หรือใช้ต้นอื่น
?? โจทย์ขุดหัวที่มีตา: **ตา = ลำต้น** → ข้อความ "รากสะสมอาหาร" ผิด · ใช้ขยายพันธุ์ได้ถูก
?? โจทย์แผนภาพเวลาของดอก: คำนวณวันที่พร้อมของแต่ละเพศ แล้วหาช่วงที่ **ซ้อนกัน** (เริ่มจากวันที่พร้อมที่ **ช้ากว่า**)

## สารอาหาร 6 กลุ่มและการทดสอบ
[[fig:p6-food-tests|ทดสอบแป้งด้วยไอโอดีน ทดสอบไขมันด้วยกระดาษ]]
| กลุ่ม | ประโยชน์ | ตัวอย่างอาหาร |
| คาร์โบไฮเดรต | ให้พลังงาน | ข้าว แป้ง น้ำตาล |
| โปรตีน | เจริญเติบโต ซ่อมแซมส่วนที่สึกหรอ | เนื้อสัตว์ ไข่ ถั่ว |
| ไขมัน | ให้พลังงาน ให้ความอบอุ่น | น้ำมัน เนย |
| วิตามิน | ช่วยให้ร่างกายทำงานปกติ | ผัก ผลไม้ |
| เกลือแร่ | สร้างกระดูก ฟัน ช่วยการทำงานของร่างกาย | นม ปลาตัวเล็ก ผัก |
| น้ำ | ช่วยลำเลียง ปรับอุณหภูมิ | น้ำดื่ม ผลไม้ |
• ให้พลังงาน: **คาร์โบไฮเดรต ไขมัน** (และโปรตีนบางส่วน) · วิตามิน เกลือแร่ น้ำ ไม่ให้พลังงาน
• ไอโอดีน: น้ำเงินเข้ม = **แป้ง** · กระดาษ ถูอาหาร: รอยโปร่งแสง = **ไขมัน**
ex: ตารางอาหาร 3 ชนิด: P (คาร์โบไฮเดรต โปรตีน) Q (ไขมัน เกลือแร่) R (วิตามิน น้ำ) → ต้องการสารอาหารครบ 6 กลุ่ม: P + Q + R · ต้องการพลังงาน: เลือก P หรือ Q (มีสารอาหารที่ให้พลังงาน) ไม่ใช่ R
ex: ผลทดสอบอาหาร 3 ชนิด: A: ไอโอดีนน้ำเงินเข้ม และมีรอยโปร่งแสง · B: ไอโอดีนไม่เปลี่ยนสี มีรอยโปร่งแสง · C: ไอโอดีนน้ำเงินเข้ม ไม่มีรอยโปร่งแสง → A มีแป้งและไขมัน · B มีไขมัน · C มีแป้ง
ex: อาหาร 4 ชนิด: A (คาร์โบไฮเดรต น้ำ) 400 · B (โปรตีน ไขมัน) 300 · C (วิตามิน เกลือแร่) 0 · D (น้ำ วิตามิน) 100 กิโลแคลอรี ต้องการรวม 700 และครบ 6 กลุ่ม → A + B + C = 400 + 300 + 0 = 700 และมีครบทั้ง 6 กลุ่ม ✓ · A + B + D = 800 ไม่ตรง ✗
?? โจทย์ผลทดสอบแป้ง/ไขมัน: ไอโอดีนเปลี่ยนเป็น **น้ำเงินเข้ม** = มีแป้ง · กระดาษ **โปร่งแสง** = มีไขมัน
?? โจทย์ตารางสารอาหาร: **ครบทุกหมู่** = มีทั้ง 6 กลุ่มเมื่อรวมกัน · ซ่อมแซมส่วนที่สึกหรอ = **โปรตีน** · ความอบอุ่น = **ไขมัน**
?? โจทย์ให้ได้พลังงานรวมเท่าที่กำหนด: **บวกให้ถึงค่านั้น และ ตรวจว่าสารอาหารครบ**
